# ZFS SnapSync logo draft

Concept generated with the built-in image generation tool. Approved and applied to the workspace and Unraid icons in 2026.09.18.04. Asset: `snapsync-logo-draft.png`.

## Generation prompt

Create a polished new logo concept for ZFS SnapSync, a standalone snapshot and replication management plugin by Adnan Nashawaty. Landscape brand presentation on a plain warm white background. One large distinctive flat vector-style emblem at left: three stacked snapshot layers integrated into two opposing sync arrows, with clever negative space subtly suggesting a Z. Deep navy and saturated teal, tiny ice-blue accent. Bold simple silhouette suitable for a small app icon, clean geometric edges, no gradients, no 3D, no shadows, no mascots, no generic database cylinder. At right beautifully typeset exact wordmark 'ZFS SnapSync' in modern geometric sans-serif, ZFS smaller than SnapSync. Below a small understated exact tagline 'Snapshots. In sync.' Generous whitespace, restrained professional open-source infrastructure branding. One concept only, no mockup devices, no extra text, no watermark.
